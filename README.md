# Wonky Window
An open-source, cross-platform fidget for your computer.

[video.webm](https://github.com/user-attachments/assets/21e6509d-b119-4299-b61d-2d519ba14107)

## Epic features!1!
1. A window with gravity and physics that can be interacted with through dragging the mouse and tossing the window around.
2. Simple and fun for the whole family!
3. Open source
4. Private; I couldn't figure out telemetry
5. Small and simple enough that nobody will notice if you are doing it when you should be doing literally anything else

## Installation
Visit the "releases" page [here](https://github.com/SupKittyMeow/Wonky-Window/releases/tag/v1.3.0-beta.1).

Pre-releases are newer, usually not buggy, however can have bugs, less features, or something else completely.
